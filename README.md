# Olympic Data Analysis Dashboard | Power BI

## 📊 Project Overview

An interactive 4-page Power BI dashboard built to analyze Olympic participation and medal performance across sports, countries, athletes, gender, and years.

## 🎯 Project Objectives

- Analyze overall Olympic medal performance
- Compare medal performance across countries/regions
- Identify top-performing athletes
- Analyze medal trends across Olympic years
- Compare male and female medal performance
- Provide interactive filtering for deeper analysis

## 📌 Dashboard Pages

### 1. Executive Overview
- Total Athletes
- Total Medals
- Gold, Silver & Bronze medals
- Medal distribution by region
- Medal count by sport
- Season filter

### 2. Country Performance
- Total medals by region
- Gold, Silver & Bronze comparison
- Region-level filtering

### 3. Athlete Analysis
- Top athletes by medal count
- Sport and gender filtering
- Detailed Sport, Event, Medal and Games analysis

### 4. Gender & Historical Trends
- Medal trends across Olympic years
- Male vs Female medal trends
- Historical performance analysis
